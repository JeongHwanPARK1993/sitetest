공문 달력 - 사용 설명
=====================

■ 설치
  압축을 푼 '공문달력' 폴더를 원하는 곳(예: 문서\공문달력)에 두고 '공문달력.exe' 를 실행하세요.
  따로 설치할 것은 없습니다. (같이 들어 있는 _internal 폴더는 지우지 마세요)
  일정 파일(공문일정.json), 설정(설정.json), 공문정리 폴더, 용어사전.txt 는
  exe 와 같은 폴더에 자동으로 만들어집니다.  → 폴더째 옮기면 그대로 이어서 쓸 수 있어요.

  ※ 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누르세요.
  ※ 백신이 막으면 '공문달력.exe' 를 예외(허용)로 등록해 주세요.

■ 위젯 (도구줄 [🧩 위젯] 에서 골라 쓰기)
  📅 달력 위젯 : 바탕화면에 깔리는 큰 월간 달력. 음력 · 24절기 · 공휴일(대체공휴일 포함) · 주 번호 · 일정
                 - 위쪽 줄을 끌면 이동, 오른쪽 아래 ◢ 로 크기 조절, 마우스 휠로 달 넘기기
                 - 일정 더블클릭 = 공문 열기, 날짜 더블클릭 = 큰 달력, 우클릭 = 메뉴(테마·음력·위치)
                 - '바탕화면에 깔기' 모드: 다른 창들 아래에 있고, 바탕화면 보기(Win+D)에도 남습니다
  📋 목록 위젯 : 오늘 근무팀과 임박한 기한만 보여 주는 작은 창
  설정 > 위젯 에서 쓸 위젯을 고르고, 설정 > 자동화 에서 '윈도우를 켜면 위젯 띄우기' 를 켜 두세요.
  위젯이 떠 있을 때 큰 창을 닫으면 위젯만 남습니다. 위젯을 모두 닫으면 프로그램이 끝납니다.

■ 공문 등록
  1) [＋ 공문 추가] 를 누르거나, 공문 PDF 를 달력 창에 끌어다 놓으세요.
  2) 제목·문서번호·새 파일 이름·날짜·할 일이 자동으로 채워집니다. 틀린 곳만 고치세요.
  3) [✔ 달력에 등록]
  → 공문 파일은 '공문정리\2026년\11월\공문제목.pdf' 처럼 연도·기안한 달 폴더에
    제목 이름으로 자동 정리됩니다. (원본 이름도 바꾸려면 '원본 파일 이름도 바꾸기' 체크)
  여러 개는 [📂 여러 개 한꺼번에] 창에 한꺼번에 끌어다 놓으면 됩니다.

■ 달력에서
  일정 한 번 클릭 = 선택 / 더블클릭 = 공문 열기 / 우클릭 = 완료·실적·삭제 메뉴
  오른쪽 '회신 할 일' 은 누르면 체크됩니다.
  Ctrl+N = 공문 추가,  Ctrl+F = 검색

■ 설정 (도구줄 [⚙ 설정], 또는 아래 상태줄 클릭)
  근무팀 / 기한 알림 / 자동화(다운로드 폴더 감시·자동 실행) / 위젯 / 공유 폴더 / 파일 이름

■ 팀원과 같이 쓰기
  설정 > 공유 폴더 에 팀 공유 드라이브 폴더를 지정하세요. 같은 폴더를 지정한 사람끼리 일정이 보입니다.

문의: 프로그램 오른쪽 아래 '만든이' 를 누르세요.

■ 공문 분석이 틀렸을 때
  분석 결과 창에서 날짜·구분을 직접 고쳐서 등록할 수 있습니다.
  자주 틀리는 말이 있으면 exe 와 같은 폴더의 '용어사전.txt' 를 메모장으로 열어,
  알맞은 [분류] 아래에 한 줄만 추가하면 다음부터 인식합니다.
    [기한용어]  이 말 뒤의 날짜는 기한 (예: 제출시한, 납부기한)
    [행사용어]  이 말 뒤의 날짜는 행사 (예: 시험일, 개최일시)
    [기한뒤말]  날짜 바로 뒤에 붙으면 기한 (예: 까지, 이내, 이전)
    [행사뒤말]  날짜 바로 뒤에 붙으면 행사 (예: 입교, 개최)
  ('금주 금요일까지', '익일까지', '접수 후 7일 이내' 같은 말로 쓴 기한도 날짜로 바꿔 줍니다.)
