업무보조 달력 - 사용 설명
==========================

■ 설치
  압축을 푼 '업무보조달력' 폴더를 원하는 곳(예: 문서\업무보조달력)에 두고 '업무보조달력.exe' 를 실행하세요.
  따로 설치할 것은 없습니다. (같이 들어 있는 _internal 폴더는 지우지 마세요)
  일정 파일(공문일정.json), 설정(설정.json), 공문정리 폴더, 용어사전.txt 는
  exe 와 같은 폴더에 자동으로 만들어집니다.  → 폴더째 옮기면 그대로 이어서 쓸 수 있어요.

  ※ 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누르세요.
  ※ 백신이 막으면 '업무보조달력.exe' 를 예외(허용)로 등록해 주세요.

■ 🐥 병아리대원 출동
  도구줄 [🐥 병아리대원 출동] (또는 트레이 우클릭 > 병아리대원 출동) 을 누르면 병아리대원이 바탕화면에 나옵니다.
  병아리대원의 원래 기능(시간·반복·일정 알람, 집중모드, 대화 ...)은 그대로이고, 달력과 연결되어
    · 주기적으로 '이 일 했어요?' 하고 물어봐요 (처리 안 한 일, 오늘 ~ 정한 날까지 + 기한 지난 일)
    · 기한 알림(3일 전 · 하루 전 · 당일 · 지남)도 병아리가 전해요
  말풍선 버튼
    [완료]     → 달력에 처리 완료 (가운데 줄)
    [진행중]   → 정한 시간(기본 4시간) 뒤에 다시 물어봄
    [알람끄기] → 그 일은 더 이상 안 물어봄 (일정 우클릭 > '병아리 알람 다시 켜기' 로 되돌림)
  설정 > 기한 알림 > 🐥 병아리대원 에서 정해요:
    물어보는 간격(1~4시간) · 확인할 범위(오늘 / 내일 / 3일 / 일주일 / 한 달) · [진행중] 다시 묻는 시간(1~8시간)
    09~18시에만 묻기 · 달력을 켜면 같이 출동
  병아리대원 트레이 아이콘을 더블클릭(알람 설정)하면 [달력 알람] 탭에서도 같은 설정을 보고 고칠 수 있고,
  '지금 달력에서 챙길 일' 목록도 보여요. 어느 쪽에서 고쳐도 서로 맞춰집니다.
  병아리대원이 꺼져 있으면 예전처럼 알림창이 떠요.

■ 한 번에 하나만 실행
  프로그램을 또 켜도 두 개가 뜨지 않고, 이미 켜진 쪽(트레이)의 달력이 나타납니다.

■ 근무팀 색 · 위젯 위치
  설정 > 근무팀 에서 색 테마(기본 / 차분 / 진하게)를 고릅니다. 칸을 칠하지 않고 '1팀·2팀·3팀' 글자 색만 바뀝니다.
  위젯은 옮기거나 크기를 바꾸면 위치가 자동 저장되어, 껐다 켜도 같은 자리에 뜹니다 (모니터가 여러 개여도).

■ 위젯에 공문 올리기
  바탕화면 달력 위젯이나 목록 위젯에 공문 PDF(여러 개 · 폴더도 가능)를 끌어다 놓으면 바로 등록 창이 열립니다.

■ 메모에 관련 공문 연결
  메모(날짜 빈 곳 더블클릭) 창의 🔗 관련 공문 에서 [＋ 달력의 공문]으로 이미 올린 공문을 고르거나,
  [＋ 파일]로 PDF/HWPX 파일을 연결합니다. 연결한 공문은 오른쪽 '관련 공문' 칸에 나오고(더블클릭 = 이동·열기),
  반대로 그 공문을 선택하면 연결한 메모가 보입니다.

■ 트레이 아이콘 (작업표시줄 오른쪽 아래, 숨겨진 아이콘 ^ 안에 있을 수 있어요)
  프로그램을 켜면 달력 아이콘이 생깁니다.
    왼쪽 클릭    = 큰 달력 열기 / 숨기기
    오른쪽 클릭  = 메뉴: 달력 위젯 켜기·끄기, 목록 위젯 켜기·끄기, 공문 추가, 설정, 종료
  창의 X 를 눌러도 프로그램은 트레이에서 계속 실행됩니다 (위젯·알림 유지). 완전히 끄려면 트레이 우클릭 > 종료.
  트레이에서 켜고 끈 위젯은 다음 실행 때도 그대로 기억합니다.

■ 위젯 (도구줄 [🧩 위젯] 에서 골라 쓰기)
  📅 달력 위젯 : 바탕화면에 깔리는 큰 월간 달력. 음력 · 24절기 · 공휴일(대체공휴일 포함) · 주 번호 · 일정
                 - 위쪽 줄을 끌면 이동, 오른쪽 아래 ◢ 로 크기 조절, 마우스 휠로 달 넘기기
                 - 일정 더블클릭 = 공문 열기, 날짜 더블클릭 = 큰 달력, 우클릭 = 메뉴(테마·음력·위치)
                 - '바탕화면에 깔기' 모드: 다른 창들 아래에 있고, 바탕화면 보기(Win+D)에도 남습니다
  📋 목록 위젯 : 오늘 근무팀과 임박한 기한만 보여 주는 작은 창
  설정 > 위젯 에서 쓸 위젯을 고르고, 설정 > 자동화 에서 '윈도우를 켜면 위젯 띄우기' 를 켜 두세요.
  큰 창을 닫아도 트레이에서 계속 실행됩니다. (트레이 아이콘이 안 만들어지는 PC에서는 위젯을 모두 닫으면 프로그램이 끝납니다.)

■ 공문 등록
  1) [＋ 공문 추가] 를 누르거나, 공문 PDF 를 달력 창에 끌어다 놓으세요.
  2) 제목·문서번호·새 파일 이름·날짜·할 일이 자동으로 채워집니다. 틀린 곳만 고치세요.
  3) [✔ 달력에 등록]
  → 공문 파일은 '공문정리\2026년\11월\공문제목.pdf' 처럼 연도·기안한 달 폴더에
    제목 이름으로 자동 정리됩니다. (원본 이름도 바꾸려면 '원본 파일 이름도 바꾸기' 체크)
  여러 개는 [📂 여러 개 한꺼번에] 창에 한꺼번에 끌어다 놓으면 됩니다.

■ 달력에서
  일정 한 번 클릭   = 오른쪽에 공문 내용이 그대로 보입니다 (기한 날짜는 노랗게 표시)
  일정 끌어다 놓기  = 다른 날로 옮기기  (Ctrl 을 누른 채 끌면 복사, 알림창의 [↶ 되돌리기] 로 취소)
  일정 더블클릭     = 설정 창: 달력에 보일 글자 · 색깔 · 날짜 · 메모 · ✔ 완료(가운데 줄)
  날짜 빈 곳 더블클릭 = 메모 / 내 일정 추가 (공문처럼 칸에 적힙니다)
                     메모 창의 🔁 반복 에서 매일 · N일마다 · 매주(요일 고르기, N주마다) · 매달 N일 ·
                     매월 초 · 매월 말 · 매월 N번째 ○요일 · 매년 을 고를 수 있습니다.
                     (주말·공휴일이면 평일로 옮기기, 끝나는 날짜·횟수 지정 가능)
                     반복 일정은 ↻ 표시가 붙고, 완료는 그날 것만, 삭제는 '그날만/전체' 를 고릅니다.
  오른쪽 [⏳ 미처리] [✔ 처리완료] 를 누르면 바로 처리 상태가 바뀝니다
  우클릭 = 메뉴 (원본 공문 열기, 실적, 삭제 ...)
  Ctrl+N = 공문 추가,  Ctrl+F = 검색

■ 설정 (도구줄 [⚙ 설정], 또는 아래 상태줄 클릭)
  근무팀 / 기한 알림 / 자동화(다운로드 폴더 감시·자동 실행) / 위젯 / 공유 폴더 / 파일 이름

■ 팀원과 같이 쓰기
  설정 > 공유 폴더 에 팀 공유 드라이브 폴더를 지정하세요. 같은 폴더를 지정한 사람끼리 일정이 보입니다.

문의: 프로그램 오른쪽 아래 '만든이' 를 누르세요.

■ 공문 분석이 틀렸을 때
  분석 결과 창에서 날짜·구분을 직접 고쳐서 등록할 수 있습니다.
  자주 틀리는 말이 있으면 exe 와 같은 폴더의 '용어사전.txt' 를 메모장으로 열어,
  알맞은 [분류] 아래에 한 줄만 추가하면 다음부터 인식합니다.
    [기한용어]  이 말 뒤의 날짜는 기한 (예: 제출시한, 납부기한)
    [행사용어]  이 말 뒤의 날짜는 행사 (예: 시험일, 개최일시)
    [기한뒤말]  날짜 바로 뒤에 붙으면 기한 (예: 까지, 이내, 이전)
    [행사뒤말]  날짜 바로 뒤에 붙으면 행사 (예: 입교, 개최)
  ('금주 금요일까지', '익일까지', '접수 후 7일 이내' 같은 말로 쓴 기한도 날짜로 바꿔 줍니다.)
