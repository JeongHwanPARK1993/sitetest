# 만든이(제작자) 크레딧 (박정환)

사용자는 만든 프로그램을 동료나 다른 사람에게 공유한다. 받은 사람이 문제를 만났을 때 누구에게 연락해야 하는지 알 수 있게, 공유하는 프로그램에 같은 모양의 만든이 안내를 넣는다. 같은 모양이어야 사용자의 프로그램이라는 것이 한눈에 알려지고, 받는 사람도 어디를 눌러야 하는지 바로 안다.

## 언제 넣나: 먼저 제안하고, 동의하면 넣는다

- **프로그램을 처음 만들거나 기능을 고치는 동안에는 넣지 않는다.** 시험용·중간 단계 프로그램에 크레딧이 붙어 있으면 거슬리고, 나중에 빼는 수고만 생긴다.
- **"프로그램화" 단계에 이르면 한 번 제안한다.** 다음 같은 때다.
  - exe(실행 파일)로 만들 때, 압축(알집)해서 배포하거나 메일·메신저로 보낼 때
  - 남에게 공유·전달한다고 할 때, 아티팩트·웹 페이지로 게시할 때
  - "완성", "마무리", "최종본", "배포용"이라고 할 때
- 제안은 짧게, 표시할 말을 고를 수 있게 한다. 예:
  > 배포용으로 만들기 전에, 화면 오른쪽 아래에 **만든이 크레딧**(누르면 메일 주소·복사 버튼 안내 창)을 넣을까요? 표시는 `만든이: 박정환` / `제작자: 박정환` 중에 고를 수 있어요.
- 사용자가 동의하면 넣고, 거절하면 그 대화에서는 다시 묻지 않는다.
- 사용자가 직접 "만든이 넣어줘", "제작자 넣어줘", "크레딧", "스킬대로 구성해줘" 등으로 요청하면 묻지 않고 바로 넣는다.
- 이미 크레딧이 들어간 프로그램을 다시 빌드할 때는 다시 묻지 않는다.

## 고정된 내용

| 항목 | 값 |
|---|---|
| 이름 | 박정환 |
| 표시 말 | `만든이` (기본) 또는 `제작자` (사용자가 고른 것) |
| 메일 | hwan9876@korea.kr |
| 인사말 | 좋은 하루 되세요 ^^ |

문구와 메일은 글자 그대로 쓴다. 인사말을 다른 말로 바꾸거나 이모지를 더하지 않는다.

## 화면 구성

1. **구석 표시**: 창의 오른쪽 아래 구석에 `만든이: 박정환`(또는 `제작자: 박정환`)을 작고 옅은 회색(8pt 안팎)으로 둔다. 프로그램의 본 기능을 가리지 않아야 하므로 눈에 띄는 버튼처럼 만들지 않는다. 마우스를 올리면 색이 진해지고 밑줄이 생기며 손가락 커서로 바뀌어, 눌러 볼 수 있다는 것을 알려 준다.
2. **클릭하면 안내 창**: 구석 표시를 누르면 부모 창 가운데에 작은 창이 뜬다. 구성은 위에서 아래로 다음과 같다.
   - `만든이: 박정환` (굵게)
   - `좋은 하루 되세요 ^^` (강조색, 배경은 창과 같은 색)
   - 메일 주소 입력칸(읽기 전용, 드래그 가능, **주소가 실제로 보여야 함**) + **복사하기** 버튼
   - 문의 안내 문구: 궁금한 점, 오류, 바라는 기능을 위 메일로 보내 달라는 말, 메일 제목 앞에 프로그램 이름을 적어 달라는 말, 오류는 어떤 파일로 무엇을 했는지 함께 알려 달라는 말
   - **닫기** 버튼
3. **복사하기**를 누르면 메일 주소가 클립보드에 들어가고, 버튼 글자가 `✔ 복사됨`으로 바뀌었다가 1.5초 뒤에 돌아온다. 복사가 됐는지 사용자가 확인할 수 있어야 하기 때문이다.
4. 창은 중복으로 열리지 않게 하고, Esc로 닫히게 한다.

## 구현 방법

### 파이썬 tkinter 프로그램 (exe 포함)

`assets/author_credit.py`를 프로젝트 폴더에 그대로 복사해서 쓴다. 직접 새로 짜지 않는 이유는 이미 동작을 확인한 코드라서 일관성이 유지되고 시간이 절약되기 때문이다. 메인 창을 만든 뒤 한 줄만 부른다.

```python
import author_credit
author_credit.add_author_credit(root, app_name="프로그램 이름")                    # 만든이: 박정환
author_credit.add_author_credit(root, app_name="프로그램 이름", label="제작자")    # 제작자: 박정환
```

- `app_name`에 프로그램의 실제 이름을 넣는다. 안내 창에 "메일 제목 앞에 [프로그램 이름]을 적어 주세요"가 표시된다.
- `place()`로 얹기 때문에 기존 `grid`/`pack` 레이아웃을 건드리지 않는다. 배경색이 부모와 다르면 `bg=`를 넘긴다 (아래 상태줄 위에 얹을 때 등).
- PyInstaller로 exe를 만들 때는 일반 import라서 따로 설정할 것이 없다. 단, 빌드 스크립트에 `author_credit.py`가 같은 폴더에 있는지만 확인한다.

**알려진 함정 (예전 코드에 있던 버그)**: 메일 칸의 `tk.StringVar`를 함수 안 지역 변수로만 두면, 함수가 끝나는 순간 변수가 사라져 **메일 칸이 빈칸으로 보인다** (복사는 되지만 주소가 안 보임). 지금 `assets/author_credit.py`는 `win.mail_var = mail_var`로 붙잡아 두어 해결했다. 직접 구현할 때도 변수를 창 객체에 붙여 두거나 `entry.insert()`로 글자를 직접 넣는다. 인사말은 `tk.Label` 대신 `ttk.Label(foreground=...)`를 써서 배경색이 창과 어긋나지 않게 한다.

### PyQt/PySide 등 다른 GUI

같은 구성과 문구로 새로 구현한다. `assets/author_credit.py`의 구조(구석 라벨, 클릭 시 대화상자, 복사 버튼 피드백)를 그대로 따른다. 클립보드는 해당 프레임워크의 기능을 쓴다.

### 웹 페이지 / HTML 아티팩트

오른쪽 아래에 `position: fixed`로 작은 텍스트 버튼을 두고, 누르면 `<dialog>` 요소로 같은 내용을 보여 준다. 복사는 `navigator.clipboard.writeText()`를 쓰고, 실패하면 입력칸을 선택해서 `document.execCommand('copy')`로 대체한다. 색상은 페이지의 라이트/다크 테마를 따른다. 구석 표시가 모바일에서 다른 버튼과 겹치지 않는지 확인한다.

### 명령줄 도구 (화면이 없는 경우)

`--about` 옵션을 추가해 만든이, 인사말, 메일, 문의 안내를 출력한다. 도움말(`--help`) 맨 아래에도 `만든이: 박정환 · hwan9876@korea.kr` 한 줄을 넣는다.

## 끝나기 전에 확인

크레딧을 넣었다고 말하기 전에 다음을 확인한다. 한 번이라도 실제로 눌러 보지 않으면 놓치기 쉬운 부분들이다.

- 구석 표시가 보이고, 다른 위젯과 겹치지 않는가
- 누르면 안내 창이 뜨고 문구와 메일이 정확한가 (`hwan9876@korea.kr`)
- **메일 칸 안에 주소가 실제로 보이는가** (빈칸이면 위 '알려진 함정')
- 복사하기를 누르면 실제로 클립보드에 들어가는가
- 창을 키우거나 줄여도 구석에 붙어 있는가

가능하면 프로그램을 실행해서 스크린샷으로 확인한다. 실행할 수 없는 환경이면 확인하지 못했다고 사용자에게 알린다.

## 사용자에게 알릴 때

크레딧을 넣었다는 한 줄과, 어디를 누르면 보이는지만 알린다.
